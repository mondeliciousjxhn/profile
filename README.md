# Modified Portfolio

Open `index.html` in a modern browser.

Changes:
- Removed Three.js/WebGL completely.
- Uses the supplied profile photo with CSS depth, perspective, glow, layered shapes, hover tilt and floating skill badges.
- Added lightweight particles, atmospheric gradients, click ripple, desktop cursor enhancement, magnetic CTAs and scroll progress.
- Theme now respects system preference on first visit and persists the selected preference.
- Mobile and reduced-motion modes automatically reduce or disable mouse-specific effects.

All professional content remains in `data.js`.
